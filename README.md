## 2. 🧩 The “Invisible” Character Limit Trick

LinkedIn allows 220 characters. But on mobile search results, only the first **100–120 characters** are visible before truncation.  

**Fix:** Put your most important keywords (role + top skill) in the first 110 characters.

**Example (bad):**  
`Experienced professional with strong leadership and communication skills seeking new opportunities in marketing.` (first 110 chars = generic fluff)

**Example (good):**  
`Marketing Manager | SEO, PPC | Grew organic traffic 120% | Seeking senior role` (first 110 chars contain role, skills, result)

## 4. 🔑 Keyword Stuffing vs. Natural Integration

| Stuffing (bad)                                | Natural (good)                                               |
| --------------------------------------------- | ------------------------------------------------------------ |
| `Python Java SQL React AWS Docker Kubernetes` | `Full‑Stack Engineer | Python, React, AWS | Built 10+ microservices` |
| `SEO PPC SEM Content Social Media Email`      | `Digital Marketing Specialist | SEO & PPC | Managed $200k ad spend` |

**How to stay natural:**  
- Use **pipes (`|`)** or **dashes (`–`)** to separate 2‑3 keywords.  
- Always pair skills with a **result** or **role**.  
- Never list more than 5 skills in a row.

## 5. 📅 How Often Should You REALLY Update?

| Situation                                              | Action                                         |
| ------------------------------------------------------ | ---------------------------------------------- |
| You started a new job                                  | Update within 3 days                           |
| You learned a high‑demand skill (e.g., AI, Salesforce) | Add immediately                                |
| You’re actively job hunting                            | Update every 2 weeks (test different keywords) |
| You’re not looking                                     | Review every 3‑6 months                        |
| You changed industries                                 | Rewrite completely                             |

**💡 Pro tip:** Keep a “master headline” in a document. Create variations for different job applications, then swap them in.

## 6. 🧠 The “Resume vs. LinkedIn” Myth

**Myth:** Your LinkedIn headline must exactly match your resume headline.  
**Fact:** Your resume headline is for a human reading a PDF. Your LinkedIn headline is for recruiter **search algorithms**.  

| Aspect           | Resume headline            | LinkedIn headline           |
| ---------------- | -------------------------- | --------------------------- |
| Length           | 1 line (optional)          | 220 characters max          |
| Keywords         | Few (context from bullets) | Many (for search)           |
| Creativity       | Low (formal document)      | Medium (still professional) |
| Update frequency | Rare (per job application) | Often (per career stage)    |

Do this: use your resume headline as a **foundation**. Then add 2–3 extra keywords for LinkedIn.

---

## 7. 🔄 What if I Have Multiple Careers / Skills?

Use the **“or” / “&”** strategy:

- `Product Manager | Growth & Data Analytics` (two related skills)  
- `Full‑Stack Developer | React or Django` (choose primary)  
- `Marketing Analyst → Product Marketing` (career bridge)

**Don’t** try to list every skill – that’s what your “Skills” section is for.
